# Public assets

The `assets/` directory will contain only media approved for publication, including:

- logo;
- mascot;
- hero/trailer;
- The Room;
- Science;
- Education;
- Office;
- Finance;
- Legal;
- Design.

Do not upload material containing:

- private names or contact details;
- filesystem paths;
- internal errors;
- unrelated overlays;
- unauthorized documents.
