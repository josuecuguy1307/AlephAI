# Aleph overview

## Specialized Workspaces

Aleph brings together six specialized environments: Science, Education, Office, Finance, Legal, and Design. Each workspace is intended to support its own tools, surfaces, artifacts, and workflow.

## The Room

The Room is Aleph's visual environment for composing an agent around the way you want it to work. It brings models, resources, tools, connectors, other agents, and their relationships into one interactive space.

## Product philosophy

Aleph is built around the idea that the interface, tools, context, and agent harness should adapt to the work. Specialized workflows and open-ended composition should coexist in the same product.

## Public-release principles

The first public release will be accompanied by documentation and media that have been reviewed for publication. Installation and quickstart guidance will be added after the release build is verified. Public materials will avoid unverified claims and will not promise compatibility with specific model names or versions.
